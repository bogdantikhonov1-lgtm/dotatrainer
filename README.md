# dotatrainer

Веб-приложение для тренировки навыка выбора героев (драфта) в игре Dota 2.
Позволяет без риска для рейтинга учиться контр-пикам и синергиям в случайно генерируемых ситуациях.

## Возможности
- Случайные сценарии драфта (союзники, враги, ваша позиция)
- Выбор лучшего героя из предложенных
- Мгновенная проверка ответа с объяснением
- Система аккаунтов с сохранением статистики (SQLite)
- Сброс прогресса
